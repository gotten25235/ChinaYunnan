## 娃娃外觀

- 正式 UI 使用自行繪製的 inline SVG，不直接嵌入參考 JPG。
- 不加吊線、掛繩或頭頂懸吊結構。
- 頭部為不完全對稱的圓潤臉型、黑色短髮與髮際線、大橢圓鼻子、簡單眼神及微笑。

- 不新增腳或誇張卡通手腳。

## 太陽造型

- 純白色實心圓心，12 道純白色細長三角光芒，每道間隔 30°，其中一道朝正上方。
- 圓心與光芒根部保留窄的透明間隙。
- 不使用藍色背景、藍色環帶、白色方框或 badge 底板；不旋轉、不做 loading spinner。
- 可有極淡白色 glow，但不能遮掉幾何間隙。

| 元素 | 數值 |
| --- | --- |
| viewBox | `0 0 100 100` |
| 圓心 | `(50, 50)` |
| 圓心半徑 | `24` |
| 第一根光芒 | `M44.2 23L50 2L55.8 23Z` |
| 其餘光芒 | 繞 `(50, 50)` 每 30° 旋轉 |
| 填色 | `#fff` |

## 構圖與動畫

- 太陽保持卡片右上高位。
- 娃娃採「太陽高、娃娃低」構圖：手機版 `.sun-wish__button` 上距 `80px`，桌面版 `87px`。
- 娃娃平常約每 3.8 秒完成一次輕微漂浮，上下約 ±2px、旋轉約 ±1.5°。
- 離開「出發提醒」Tab 時只暫停持續漂浮；計數與太陽生命週期不重置。
- 太陽初始完全不可見，位於卡片下方並由天空容器裁切。
- 不得因位置調整產生白色直條、白底遮罩或其他非設計背景。

## 點擊生命週期

| 狀態 / 操作 | 行為 |
| --- | --- |
| 第一次點擊 | 計數 +1；娃娃約 0.95 秒祈晴晃動；太陽開始升起 |
| 太陽升起 | 延遲約 0.15 秒，以 3 秒由卡片下方升至右上並淡入 |
| 升起完成 | 停留約 8 秒 |
| 停留結束 | 原地約 1.3 秒淡出，不向下沉落 |
| 升起中再點 | 計數 +1、娃娃再次祈晴、太陽微亮；不重啟升起，完成後仍完整停留 8 秒 |
| 停留中再點 | 計數 +1、再次祈晴與微亮；重新計算 8 秒停留 |
| 淡出中再點 | 取消淡出並恢復顯示，再停留 8 秒；不從底部重升 |
| 完全消失後再點 | 重新由底部升起 |

同一時間只保留一個生命週期 timer，快速連點不得被舊 timer 提前隱藏。

## 計數、主題與無障礙

- 每次原生按鈕 click 都 +1；Enter / Space 亦可操作。
- 計數使用 localStorage key `yunnan-2026-sun-wish-count-v1` 保存；重新整理、關閉後再開啟仍保留。只有使用者清除該網站的瀏覽器網站資料／儲存空間時才會歸零；不使用 Cookie 或後端。
- 沿用網站既有 Theme / Settings，不另建主題控制器。
- 卡片不可造成橫向捲動，太陽不得遮住娃娃與文字。
- 裝飾 SVG 對輔助科技隱藏；祈晴次數使用 polite live region。
- `prefers-reduced-motion: reduce` 時停止持續漂浮，取消太陽位移與雲層 transition；點擊仍保留計數與 8 秒停留。

## Runtime Ownership

- `js/tips.js` 擁有出發提醒 renderer 與晴天娃娃 runtime state。
- `.sun-wish*` 樣式集中在 `css/style.css` 的 Tips / Sun Wish 區段。
- App 只透過中央 action router 呼叫 `tipsSystem.handleAction()`；不另加 document-level click router。
- 娃娃、漂浮、祈晴、太陽各自使用不同 wrapper，避免動畫同時覆寫同一個 `transform`。
- 未來若改成 GIF，只替換 `.sun-wish__figure` 內的娃娃本體；按鈕、計數、太陽與 timer 不變。若 GIF 納入 runtime，必須本地化並加入離線 manifest。

## 驗收重點

- `準備好，慢慢玩。` 維持不變，晴天娃娃位於標題與原有提醒卡之間。
- 初始太陽完全隱藏；太陽為白色圓心 + 12 道三角光芒，無藍底或旋轉。
- 娃娃無吊線，白色偏瘦布身與紅結維持。
- 首次點擊約 3 秒升起，停留 8 秒後淡出；快速連點不累積舊 timer。
- 切換 Tab、重新整理或關閉後再開啟都不重置計數；只有清除網站資料才歸零；離開出發提醒時漂浮暫停。
- 手機無橫向捲動；深淺主題與 reduced-motion 正常。
- 太陽保持右上高位；娃娃上距手機 `80px`、桌面 `87px`。
- PUBLIC 只顯示「圖片參考 ↗」；DEV 才追加「· 來源頁 ↗」。
