## 正式 UI

- 保留出發提醒標題：`準備好，慢慢玩。`
- 晴天娃娃固定放在標題下方、原有提醒卡與航班資訊上方。
- 唯一主要操作是「點晴天娃娃」；正式卡片不得再加入「重置祈禱」、主題切換或其他 demo toggle。
- 中央文案保留：

```text
一路放晴 ☀️
雲散一點，陽光多一點。
```

- 本輪彩蛋提示顯示於中央文案下方，例如：`本輪 3 次 · 下一個彩蛋：第 5 次`。
- 總祈晴數與完成輪數移到卡片左下角，以兩個小型狀態膠囊顯示，不做成按鈕：

```text
🙏 87    ☀️ 4
```

  - `🙏 N`：累積祈晴次數。
  - `☀️ R`：完整完成的祈晴輪數。
  - 兩者只顯示狀態，不可點擊；完整語意由 `aria-label` 提供。
- 圖片 credit 固定在右下角，與左下狀態分離。

## 太陽與天空

- 太陽為純白實心圓心 + 12 道純白細長三角光芒，每道間隔 30°，其中一道朝正上方。
- 不使用藍色背景、藍色環帶、白色方框或 badge 底板；太陽不旋轉。
- 太陽保持卡片右上高位；初始完全隱藏於卡片下方。
- 新版以單一 `progress`（0～1）同步驅動太陽高度與天空光照。
- 光照由右上方開始擴張；雲層有低對比亮邊與慢速漂移。
- 每次點擊都會把雲向外推一點並累積本輪亮度；連點約 20 次可把卡片柔和照到接近全白。
- 太陽淡出時背景同步恢復，完整消失才完成一輪。

## 點擊生命週期

| 狀態 / 操作 | 行為 |
| --- | --- |
| 隱藏後第一次點擊 | 約 2 秒由下方升起；總次數 +1；本輪次數 +1 |
| 升起途中再點 | 從目前位置加速，剩餘時間約縮至 58%；不重播升起 |
| 到頂 | 停留 3 秒 |
| 到頂後再點 | 太陽輕彈、亮度累加，重新計算 3 秒停留 |
| 停留結束 | 原地淡出 1 秒，背景同步變暗 |
| 淡出中再點 | 約 240ms 恢復亮度，仍屬同一輪，之後重新停留 3 秒 |
| 完整消失 | 完成輪數 +1，本輪次數歸零；下次點擊開始新一輪 |

- 彩蛋以 7 次為一個循環：第 1／3／5／7 次觸發，下一循環為第 8／10／12／14 次，再下一循環為第 15／17／19／21 次，以此類推；第 3／5／7 對應位置會短暫觸發笑臉、放晴、散雲效果。
- 第 8 次以後持續累加亮度與回饋，不設強制重播或遊戲上限。
- 快速連點不得累積舊 timer；共用單一太陽 animation state。

## 計數與保存

- 正式網站總祈晴次數：`yunnan-2026-sun-wish-count-v1`。
- 正式網站完成輪數：`yunnan-2026-sun-wish-rounds-v1`。
- 計數使用 BigInt 十進位字串保存，避免超過 Number 安全整數後無法繼續累加。
- 重新整理、關閉頁面後再開啟仍保留總祈晴數與完成輪數。
- 未完成的動畫不跨重新整理復原；重新載入後由太陽隱藏待機開始。
- 正式 UI **沒有重置按鈕**。只有使用者自行清除該網站的瀏覽器網站資料／localStorage 時，持久計數才會歸零。
- 預覽頁使用獨立 key：`yunnan-2026-sun-wish-count-preview-v1` 與 `yunnan-2026-sun-wish-preview-rounds-v1`，不污染正式網站。

## 主題與無障礙

- 正式網站完全沿用 `settings.js` 既有 `system / light / dark` Theme ownership，不另建主題控制器，也不提供晴天娃娃專屬 toggle。
- 淺色天空使用偏鼠尾草綠底色與冷灰綠雲層；深色天空使用深綠灰底與灰綠雲層。
- 亮度高到接近白色時，文字、左下狀態與右下 credit 必須切回深色系，維持可讀性。
- 裝飾 SVG 對輔助科技隱藏；左下統計為 polite live region。
- `prefers-reduced-motion: reduce` 時停止持續漂浮與雲漂移，取消太陽位移／輕彈等動態，但保留計數、靜態光照與 3 秒停留邏輯。

## Runtime Ownership

- `js/tips.js` 擁有出發提醒 renderer，以及晴天娃娃的 `count / rounds / roundTaps / sunState / progress / timer / requestAnimationFrame`。
- `.sun-wish*` 樣式集中在 `css/style.css` 的 Tips / Sun Wish 區段。
- App 只透過中央 action router 呼叫 `tipsSystem.handleAction()`；不另加 document-level click router。
- 娃娃、漂浮、祈晴、太陽各自使用不同 wrapper，避免動畫互相覆寫同一個 transform。
- Theme 不屬於 Tips；Tips 只讀 `html[data-theme]` 最終結果。

## 驗收重點

- `準備好，慢慢玩。` 維持不變，晴天娃娃位於標題與原有提醒卡之間。
- 正式卡片沒有「重置祈禱」按鈕、沒有淺／深色 toggle、沒有其他 demo control。
- 左下顯示 `🙏 N` 與 `☀️ R`，右下維持來源 credit；窄手機不可互相遮住或造成橫向捲動。
- 初始太陽完全隱藏；首次點擊約 2 秒升起、停留 3 秒、淡出 1 秒。
- 連點可加速升起、延長停留、逐步推散雲並把天空照亮；第 8 次以後不重播升起。
- 完整淡出後才增加完成輪數。
- 重新整理保留總祈晴數與完成輪數，但不續播上一輪動畫。
- 深淺主題、手機版、桌機版與 reduced-motion 均正常。
- PUBLIC 只顯示「圖片參考 ↗」；DEV 才追加「來源頁 ↗」。
