## 太陽與天空

- 太陽為純白實心圓心 + 12 道純白細長三角光芒，每道間隔 30°，其中一道朝正上方。
- 不使用藍色背景、藍色環帶、白色方框或 badge 底板；太陽不旋轉。
- 太陽保持卡片右上高位；初始完全隱藏於卡片下方。
- 新版以單一 `progress`（0～1）同步驅動太陽高度與天空光照。
- 光照由右上方開始擴張；雲層有低對比亮邊與慢速漂移。
- 每次點擊都會把雲向外推一點並累積目前這次可見場景的亮度；連點約 20 次可把卡片柔和照到接近全白。
- 太陽淡出時背景同步恢復；完整消失只重置暫態視覺場景，不產生「完成輪數」。

## 點擊生命週期

| 狀態 / 操作 | 行為 |
| --- | --- |
| 太陽隱藏時點擊 | 約 2 秒由下方升起；趣味祈晴紀錄 +1 |
| 升起途中再點 | 從目前位置加速，剩餘時間約縮至 58%；不重播升起 |
| 到頂 | 停留 3 秒 |
| 到頂後再點 | 太陽輕彈、亮度累加，重新計算 3 秒停留 |
| 停留結束 | 原地淡出 1 秒，背景同步變暗 |
| 淡出中再點 | 約 240ms 恢復亮度，之後重新停留 3 秒 |
| 完整消失 | 暫態 `sceneTaps` 與視覺效果歸零；永久 `🙏 N` 不變 |

- 彩蛋以**永久累積的祈晴總數**為準，每 7 次循環：`1/3/5/7 → 8/10/12/14 → 15/17/19/21 → …`。重新整理後仍依累積總數接續，不依太陽是否曾淡出。
- 正式 UI **不顯示任何彩蛋文字敘述或下一次提示**；差異只透過視覺呈現。
- 視覺差異：循環第 1 格加強太陽／天空脈衝；第 3 格切換彎眼笑臉約 2.2 秒；第 5 格笑臉＋明顯放晴約 2.5 秒；第 7 格笑臉＋放晴＋雲層大幅散開約 3 秒。
- 第 8 次以後只是不斷重複同一個 7 次視覺循環；`🙏 N` 純粹是好玩的累積紀錄，沒有遊戲進度、獎勵或實質效果判定。
- 快速連點不得累積舊 timer；共用單一太陽 animation state。

## 計數與保存

- 正式網站只保存總祈晴次數：`yunnan-2026-sun-wish-count-v1`。
- `🙏 N` 僅作趣味紀錄，使用 BigInt 十進位字串保存，避免超過 Number 安全整數後無法繼續累加。
- 不再讀寫完成輪數；舊版曾使用的完成輪數 localStorage 值即使仍留在瀏覽器，也不再影響 UI 或互動。
- 重新整理、關閉頁面後再開啟仍保留 `🙏 N`；未完成的太陽位置、亮度、散雲與 `sceneTaps` 不跨重新整理復原。
- 正式 UI **沒有重置按鈕**。只有使用者自行清除該網站的瀏覽器網站資料／localStorage 時，持久祈晴紀錄才會歸零。
- 預覽頁使用獨立 key：`yunnan-2026-sun-wish-count-preview-v1`，不污染正式網站。

## 主題與無障礙

- 正式網站完全沿用 `settings.js` 既有 `system / light / dark` Theme ownership，不另建主題控制器，也不提供晴天娃娃專屬 toggle。
- 淺色天空使用偏鼠尾草綠底色與冷灰綠雲層；深色天空使用深綠灰底與灰綠雲層。
- 亮度高到接近白色時，文字、左下狀態與右下 credit 必須切回深色系，維持可讀性。
- 裝飾 SVG 對輔助科技隱藏；左下統計為 polite live region。
- `prefers-reduced-motion: reduce` 時停止持續漂浮與雲漂移，取消太陽位移／輕彈等動態，但保留計數、靜態光照與 3 秒停留邏輯。

## Runtime Ownership

- `js/tips.js` 擁有出發提醒 renderer，以及晴天娃娃的 `count / sceneTaps / sunState / progress / timer / requestAnimationFrame`。`count` 是唯一持久計數；`sceneTaps` 只驅動當次可見場景的推雲／亮度，不顯示成進度。
- `.sun-wish*` 樣式集中在 `css/style.css` 的 Tips / Sun Wish 區段。
- App 只透過中央 action router 呼叫 `tipsSystem.handleAction()`；不另加 document-level click router。
- 娃娃、漂浮、祈晴、太陽各自使用不同 wrapper，避免動畫互相覆寫同一個 transform。
- Theme 不屬於 Tips；Tips 只讀 `html[data-theme]` 最終結果。

## 驗收重點

- `準備好，慢慢玩。` 維持不變，晴天娃娃位於標題與原有提醒卡之間。
- 正式卡片沒有「重置祈禱」按鈕、沒有淺／深色 toggle、沒有其他 demo control。
- 左下只顯示 `🙏 N` 趣味紀錄，右下維持來源 credit；不得再出現完成輪數、本輪次數或彩蛋文字提示；窄手機不可互相遮住或造成橫向捲動。
- 初始太陽完全隱藏；首次點擊約 2 秒升起、停留 3 秒、淡出 1 秒。
- 連點可加速升起、延長停留、逐步推散雲並把天空照亮；第 8 次以後不重播升起。
- 笑臉觸發時一般表情整組隱藏，不能有舊眼睛／鼻口線條重疊。
- 重新整理只保留總祈晴數，不續播上一個暫態動畫。
- 深淺主題、手機版、桌機版與 reduced-motion 均正常。
- PUBLIC 只顯示「圖片參考 ↗」；DEV 才追加「來源頁 ↗」。
