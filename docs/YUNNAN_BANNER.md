# 雲南慢時光｜動態橫幅 V1

本文件專門記錄首頁動態雲霧橫幅的互動、效能、安全與整合邊界。橫幅已直接合併到主網站「旅程總覽」上方，不使用 iframe，也不建立獨立 Tab。

## 功能

- 預設為播放狀態；頁面首次載入時會自動執行一次「撥雲放晴」開場動畫。
- 使用者點擊橫幅空白區時，會以點擊位置為中心快速撥開雲霧；撥開後維持晴朗 3 秒，再讓雲霧緩慢回來。
- 滑鼠／觸控移動可產生輕量視差；拖曳與點擊使用位移門檻區分，避免滑動時誤觸放晴。
- 點選昆明、大理、麗江、香格里拉等路線節點時，會切換照片說明與視差焦點，並觸發一次放晴效果；晴朗狀態維持 3 秒。
- 右上角控制維持 `Ⅱ / ▶` 圖示：`Ⅱ` 暫停、`▶` 播放。
- 使用者按下暫停後，狀態會寫入 `localStorage`；重新整理或下次開啟仍維持暫停。
- 暫停狀態重新整理時，標題、城市、日期與說明文字直接顯示，不會停在文字進場動畫的透明狀態。
- 從暫停切回播放時，會重新執行一次「撥雲放晴」開場動畫，再接回慢速環境動畫。
- 頁面切到背景或橫幅離開可視區域時會停止動畫排程，回到畫面後續播，但不重播初始開場。

## UI

- 橫幅位於主網站「旅程總覽」最上方，取代舊靜態 Hero。
- 不顯示「點一下 · 雲開見晴」或其他點擊提示文字；互動功能本身保留。
- 底部城市節點只控制橫幅 Caption、焦點與放晴效果，不直接切換 Day 1–8。
- 主網站正式日期與 Day 導航仍由既有旅程資料與行程元件負責。
- 橫幅寬度沿用主網站 gutter：一般畫面左右約 30px，窄手機左右 18px；最大寬度 1240px。

## 效能與安全

- WebGL 雲霧使用低解析度畫布與低功耗設定，避免以全螢幕像素持續渲染。
- `pointermove` 經 `requestAnimationFrame` 合併更新，避免高頻事件直接重繪。
- 撥雲動畫共用同一組狀態，不會因連點而累積多個動畫實例或計時器。
- `IntersectionObserver` 在橫幅離開可視區域時停止動畫排程。
- 頁面進入背景時停止動畫排程，回到前景後依原狀態續播。
- WebGL context lost 時會停用程序霧層，避免錯誤持續影響頁面。
- 使用單一 V1 現代瀏覽器實作，不保留舊版相容分支。

## 狀態記憶

播放／暫停使用以下 localStorage key：

```text
yn-banner-animation-paused-v1
```

值為 `1` 代表使用者主動暫停；其他狀態視為播放。這是橫幅自己的 UI 狀態 key，與主網站 release version 分開，不因一般版本升級而改名。

## 圖片與授權

- 橫幅前景與背景共用主專案既有的 `images/blue-moon-valley.webp`，不再把同一張 WebP 以 Base64 內嵌兩次。
- 該圖也是原主網站 Hero 使用的藍月谷照片，因此沿用現有圖片來源與授權紀錄，不新增第二份圖片資產。
- 圖片來源與授權仍以 `trip-data.json` / generated source ledger 的既有紀錄為準。

## 主網站整合

橫幅拆成三部分直接納入主專案：

- `index.html`：`<section class="yn-banner">` 結構。
- `css/banner.css`：只使用 `.yn-*` 命名空間，不修改全站 `body`。
- `js/banner.js`：動畫、WebGL、視差、路線節點與暫停狀態。

主網站 `js/app.js` 只負責把旅程日期寫入橫幅；橫幅不依賴主網站的 Day 卡片、地圖或 Tab 切換。

## 離線與版本

- `css/banner.css` 與 `js/banner.js` 屬 App Shell，必須加入 Service Worker 與 `offline-manifest.json` 的核心資產。
- 兩個檔案在 `index.html` 使用與主程式一致的 `?v=<release>` cache busting。
- 一般 release 只更新軟體版本，不改 `yn-banner-animation-paused-v1`。

## 維護原則

- 不重新加入已移除的右上提示文字。
- 不把橫幅再包成 iframe 或第二套獨立頁面。
- 不複製 `blue-moon-valley.webp`；前景／背景維持共用同一檔案。
- 若未來修改雲霧或拖曳效果，優先維持「不累積動畫、不阻塞主執行緒、離屏停止」三項約束。
