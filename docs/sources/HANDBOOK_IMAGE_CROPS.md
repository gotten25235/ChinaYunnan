## 使用規則

- 地點、飯店、景點、店家與拍照點：只顯示能直接對應主體的 `exact` / `verified` 圖片。
- `reference_only`：不顯示主圖。
- `representative`：只允許廣義食物／購物類示意，且 UI 必須標示「示意圖」。
- 大陸版：遠端圖片若沒有精準本地化版本，直接顯示「無此圖」；禁止用同城市、附近景點、同類商品或同品牌其他分店照片補位。
- 若之後找到可確認且可合法保存的精準網頁圖片，可再取代「無此圖」，但必須同步記錄來源與主體核對依據。
