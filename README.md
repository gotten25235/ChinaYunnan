# 雲南慢時光 · 8 日雲南旅程

這是一個為手機與電腦使用設計的 8 日雲南旅程網頁。主要內容包含每日行程、地圖探索、住宿附近夜遊、美食、購物、收藏、拍照／故事，以及出發提醒。

## 開啟網站

請使用瀏覽器開啟網站首頁。建議使用 HTTPS 網址；手機可直接加入主畫面，旅途中會比較方便。

網站提供 **國際版 / 大陸版** 連網模式，**預設為國際版**。可在「探索地圖」或「出發提醒」的下拉選單切換；切換後頁面會重新整理一次套用。模式偏好只保存在目前瀏覽器。

- **國際版**：OpenStreetMap 底圖、保留原始外部實拍。
- **大陸版**：高德底圖 + GCJ-02 座標校正；圖片與國際版使用同一個「正確主體」photo record。已本地化 WebP 優先；仍是遠端的精準來源圖也會嘗試載入並由 Image Cache 保存，失敗才顯示「無此圖」。絕不改拿附近景點、同城市或同類照片補位。Google / Instagram / Wikimedia 等查核網址在中國大陸仍可能無法直接開啟。
- **天氣來源不跟連網模式綁死**：兩個模式都固定使用「高德天氣 → QWeather Grid → Open-Meteo」的優先順序。

網站內嵌圖片使用較省流量的 WebP；已看過的圖片會盡量使用手機本機快取，以減少重複下載流量。地圖底圖、即時導航與天氣更新仍需要網路連線。

### 圖片正確性規則

具名地點、飯店、景點、店家與明確拍照點使用 `exact` / `verified` 主體圖。交通、沒有指定單一場地的活動、料理與文化故事可使用真正符合主題的 `illustrative` / `representative` / `context` 圖，畫面會明確標示「示意圖」或「背景圖」。`reference_only` 永遠不顯示。不論哪種模式，都禁止拿同城市、附近景點、同品牌或同類但非同一主體的照片硬補。

定案手冊中能明確對應景點的照片會直接裁切為本地 WebP，頁碼與裁切清單記錄於 `docs/sources/HANDBOOK_IMAGE_CROPS.md`。

## 主要分頁

- **旅程總覽**：查看 Day 01–08 每日路線、住宿、主要行程與旅程日天氣；點「展開這一天」可閱讀完整內容。玉龍雪山／雲杉坪、普達措會另顯示高海拔區域預報。
- **探索地圖**：查看行程地點與附近可玩內容。手機直接左右滑動地點卡；電腦可用滑鼠按住地點列左右拖曳。
- **夜間逍遙**：依日期查看飯店附近的散步、夜市或晚間活動建議。
- **當地必吃**：依城市瀏覽雲南料理與小吃。
- **雲南必買**：查看伴手禮與適合當地享用的品項。
- **我的收藏**：集中顯示已加入收藏的景點、美食與購物內容。
- **拍照・有風／風俗與故事**：查看拍照地點、文化背景與旅途中值得留意的故事。
- **出發提醒**：查看航班、導航設定、旅行提醒與內容查核來源。

## 手機操作

主分頁可直接點上方／下方導覽切換；一般頁面區域也支援左右滑動切換分頁。卡片橫向列表本身則保留自己的左右滑動，不會被主分頁手勢搶走。

在「探索地圖 → 滑動探索地點」：

- **短按地點卡**：定位／查看附近內容。
- **長按約半秒後放開**：開啟完整內容 Reader。
- **左右滑動**：自由瀏覽地點卡，不會強制停在某一張卡片。

## 電腦操作

在「探索地圖 → 滑動探索地點」可用滑鼠左鍵按住地點列直接左右拖曳。短按仍是定位，按住不移動約半秒則可開啟完整內容。

旅程總覽與時刻表等橫向內容也可使用滑鼠拖曳瀏覽。

## 完整內容 Reader

點開景點、美食、購物、故事等完整內容後，可查看較完整的說明、圖片、地址、來源與導航操作。關閉 Reader 後會回到原本閱讀的位置。

## 收藏

點卡片上的愛心即可加入「我的收藏」。收藏保存在目前瀏覽器中，不會自動同步到其他手機或電腦；清除瀏覽器網站資料後也可能消失。

## 地圖與導航

網站預設使用高德地圖作為導航服務，也可切換為 Google 地圖。**大陸版會在載入時優先恢復高德導航**；仍可手動改成 Google，但中國大陸一般網路通常不可用。

探索地圖的底圖會跟著連網模式切換：國際版使用 OpenStreetMap；大陸版使用高德底圖。正式旅程資料中的座標仍維持 WGS84，大陸版只在顯示地圖時轉成 GCJ-02，因此不會為了中國底圖改壞原始座標。

Leaflet 地圖程式會依模式優先從國際 / 中國 CDN 載入，成功後由 Service Worker 快取，降低重複下載；若地圖程式或底圖暫時連不上，下方地點清單、地址複製、收藏與導航連結仍可使用。

地點座標與營業資訊以網站整理內容為參考；實際出發與當天導航仍應以現場、官方公告及導航 App 的即時資訊為準。

## 天氣

每日天氣固定採三級 provider chain：**1 高德天氣 → 2 QWeather Grid → 3 Open-Meteo**。高德優先提供行政區預報；QWeather Grid 以經緯度格點資料補齊；Open-Meteo 再補較長預報範圍、降雨機率、體感、風速與 UV 等缺欄位。單一來源沒設定、超出預報範圍或連線失敗時，會自動往下一層降級；不是把不同來源互相覆蓋成不明資料。

高德 Web Service Key、QWeather API Host 與 QWeather API Key 可在「出發提醒 → 天氣 API 設定」輸入，只保存在目前瀏覽器，不寫進 ZIP。若兩組 Key 都未設定，網站會直接使用免 Key 的 Open-Meteo。QWeather WebAPI v7 Grid Weather 已列為棄用、目前仍可用；本版先呼叫 Grid Weather，若該端點停用會在同一 QWeather provider 內自動改用官方現行 1 km 經緯度每日預報。

主畫面只顯示最高／最低溫、天氣狀況與降雨機率；展開完整行程後可查看更多指標與簡單旅遊提醒。天氣最多每 1 小時重新抓取一次，並保留最後一次成功資料供離線時參考。預報會隨時間更新，出發當天仍應以最新氣象資訊與現場公告為準。

## 出發提醒

「內容來源與查核」預設為**閉合**，需要時點一下標題即可展開；再次點擊即可收合。

航班、景區、交通、飯店與營業時間可能變動，出發前仍建議再確認實際票券、官方公告與旅行社通知。

## 離線與省流量

網站只在第一次打開某個分頁時建立該分頁內容，避免首頁一次載入所有圖片；已使用過的程式檔與圖片也會保留在瀏覽器快取中，因此第二次之後瀏覽通常會比第一次省流量、載入更快。

但以下內容仍可能需要網路：

- 國際版第一次看到的外部實拍
- 地圖底圖
- Leaflet 第一次載入（成功後會進 App Cache）
- 天氣首次取得／更新
- 高德／Google 導航
- 外部官方來源連結

圖片補足以「同一主體」為前提：已能從定案手冊明確核對的景點優先使用本地手冊截圖；其餘找到精準來源圖後保留其原始 URL。國際版／大陸版都嘗試同一張正確圖片，第一次成功後由 Service Worker Image Cache 減少重抓；載入失敗才顯示「無此圖」，不會以區域參考圖硬補。若要把遠端精準圖進一步打包成本地，可在可正常連線的電腦執行 `LOCALIZE_IMAGES.bat`。

若網站剛更新，重新整理後可能需要一次網路連線取得新版內容。


## 必吃／必買與鄉野奇談

美食與購物會把「必吃／必買」優先項目排在前面；這是依本次路線與來源資料整理的優先級，不代表指定餐廳或保證可攜帶入境。風俗故事中的「鄉野奇談」是地方傳說／民俗閱讀，會明確標示非史實或非已證實靈異事件。
