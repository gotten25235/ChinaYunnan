# 雲南慢時光 · 8 日雲南旅程

> 快速入口：頁面右上角「離線準備」按鈕會依狀態顯示「離線已備妥／離線可用」，點一下直接跳到「設定」分頁中的離線準備卡。


這是一個為手機與電腦使用設計的 8 日雲南旅程網頁。主要內容包含每日行程、地圖探索、住宿附近夜遊、美食、購物、收藏、拍照／故事，以及出發提醒。

## 開啟網站

請使用瀏覽器開啟網站首頁。建議使用 HTTPS 網址；手機可直接加入主畫面，旅途中會比較方便。

### 出國前先做一次離線準備

1. 在有網路時開啟網站。
2. 到 **設定 → 離線準備**，先選擇要下載的內容，再按 **「下載已選內容」**。預設會全選；「網頁核心與其他資料」是必要項目，旅行照片與天氣可個別取消。
3. 同一區塊提供 **清除照片快取 / 清除天氣快取 / 清除全部離線下載**，方便出發前重新整理；這些清除操作會保留收藏、自定義地標、連網模式、導航偏好與天氣 API Key。
4. 等畫面顯示 **「✓ 已選內容準備完成」**。完成判定只看你目前勾選的內容；如果取消「旅行照片」，照片未下載不會再讓整個離線狀態顯示失敗。
5. 建議再把網站加入手機主畫面，並開一次飛航模式重新開啟測試。

之後即使沒有網路，行程、飯店、景點、照片、美食、故事、收藏、自定義地標與探索地圖的 **離線地標簡圖** 仍可使用。天氣會顯示最後一次成功取得的資料；OpenStreetMap／高德道路底圖、即時天氣更新與真正的導航仍需要網路或地圖 App。

「下載已選內容」是明確的完整性檢查，不是只依賴「曾經看過」的瀏覽器快取。下載項目分為：固定的「網頁核心與其他資料」、可選的「旅行照片」、可選的「天氣離線資料」。旅行照片同時包含 ZIP 內本地照片與仍需跨站抓取的精準遠端照片，兩者都放進獨立 Image Cache，因此可以整包下載或整包清除。若已勾選照片且有任何照片失敗，「查看未下載項目」會直接列出缺失並提供「只重試未下載照片」。

網站提供 **國際版 / 大陸版** 連網模式，**預設為國際版**。可在「設定」分頁切換；切換後頁面會重新整理一次套用。模式偏好只保存在目前瀏覽器。

- **國際版**：OpenStreetMap 底圖、保留原始外部實拍。
- **大陸版**：高德底圖 + GCJ-02 座標校正；圖片與國際版使用同一個「正確主體」photo record。已本地化 WebP 優先；仍是遠端的精準來源圖也會嘗試載入並由 Image Cache 保存，失敗才顯示「無此圖」。絕不改拿附近景點、同城市或同類照片補位。Google / Instagram / Wikimedia 等查核網址在中國大陸仍可能無法直接開啟。
- **天氣來源不跟連網模式綁死**：兩個模式都固定使用「高德天氣 → QWeather Grid → Open-Meteo」的優先順序。

網站內嵌圖片使用較省流量的 WebP；已看過的圖片會盡量使用手機本機快取，以減少重複下載流量。地圖底圖、即時導航與天氣更新仍需要網路連線。

### 圖片正確性規則

具名地點、飯店、景點、店家與明確拍照點使用 `exact` / `verified` 主體圖。交通、沒有指定單一場地的活動、料理與文化故事可使用真正符合主題的 `illustrative` / `representative` / `context` 圖，畫面會明確標示「示意圖」或「背景圖」。`reference_only` 永遠不顯示。不論哪種模式，都禁止拿同城市、附近景點、同品牌或同類但非同一主體的照片硬補。

定案手冊中能明確對應景點的照片會直接裁切為本地 WebP，頁碼與裁切清單記錄於 `docs/sources/HANDBOOK_IMAGE_CROPS.md`。

## 主要分頁

- **旅程總覽**：查看 Day 01–08 每日路線、住宿、主要行程與旅程日天氣；點「展開這一天」可閱讀完整內容。玉龍雪山／雲杉坪、普達措會另顯示高海拔區域預報。
- **探索地圖**：查看行程地點與附近可玩內容。手機直接左右滑動地點卡；電腦可用滑鼠按住地點列左右拖曳。
- **夜間逍遙**：依日期查看飯店附近的散步、夜市或晚間活動建議。
- **當地必吃**：依城市瀏覽雲南料理與小吃。
- **雲南必買**：查看伴手禮與適合當地享用的品項。
- **我的收藏**：集中顯示已加入收藏的景點、美食與購物內容。
- **拍照・有風／風俗與故事**：查看拍照地點、文化背景與旅途中值得留意的故事。
- **出發提醒**：查看航班、旅行提醒與內容查核來源。
- **設定**：集中管理介面版面、國際／大陸連網模式、導航、天氣 API 與離線準備。

## 手機操作

主分頁可直接點上方／下方導覽切換；一般頁面區域也支援左右滑動切換分頁。手機可觸控滑動；電腦版可用滑鼠拖曳或 precision touchpad 水平手勢切換。卡片橫向列表、地圖、表單等元件本身仍保留自己的操作，不會被主分頁手勢搶走。
- 手機使用「電腦版」時，主內容區的空白背景也可左右滑動切換 Tab；卡片、地圖、橫向 Rail 與表單仍保留原生操作。

在「探索地圖 → 滑動探索地點」：

- **短按地點卡**：定位／查看附近內容。
- **長按約半秒後放開**：開啟完整內容 Reader。
- **左右滑動**：自由瀏覽地點卡，不會強制停在某一張卡片。

## 電腦操作

在「探索地圖 → 滑動探索地點」可用滑鼠左鍵按住地點列直接左右拖曳。短按仍是定位，按住不移動約半秒則可開啟完整內容。

旅程總覽與時刻表等橫向內容也可使用滑鼠拖曳瀏覽。

## 完整內容 Reader

點開景點、美食、購物、故事等完整內容後，可查看較完整的說明、圖片、地址、來源與導航操作。關閉 Reader 後會回到原本閱讀的位置。

## 收藏

點卡片上的愛心即可加入「我的收藏」。收藏保存在目前瀏覽器中，不會自動同步到其他手機或電腦；清除瀏覽器網站資料後也可能消失。

## 地圖與導航

網站預設使用高德地圖作為導航服務，也可切換為 Google 地圖。**大陸版會在載入時優先恢復高德導航**；仍可手動改成 Google，但中國大陸一般網路通常不可用。

探索地圖的底圖會跟著連網模式切換：國際版使用 OpenStreetMap；大陸版使用高德底圖。正式旅程資料中的座標仍維持 WGS84，大陸版只在顯示地圖時轉成 GCJ-02，因此不會為了中國底圖改壞原始座標。

Leaflet 地圖程式會依模式優先從國際 / 中國 CDN 載入，成功後由 Service Worker 快取，降低重複下載；若地圖程式或底圖暫時連不上，下方地點清單、地址複製、收藏與導航連結仍可使用。

地點座標與營業資訊以網站整理內容為參考；實際出發與當天導航仍應以現場、官方公告及導航 App 的即時資訊為準。

## 天氣

每日天氣固定採三級 provider chain：**1 高德天氣 → 2 QWeather Grid → 3 Open-Meteo**。高德優先提供行政區預報；QWeather Grid 以經緯度格點資料補齊；Open-Meteo 再補較長預報範圍、降雨機率、體感、風速與 UV 等缺欄位。單一來源沒設定、超出預報範圍或連線失敗時，會自動往下一層降級；不是把不同來源互相覆蓋成不明資料。

高德 Web Service Key、QWeather API Host 與 QWeather API Key 可在「設定 → 天氣 API 設定」輸入，只保存在目前瀏覽器，不寫進 ZIP。若兩組 Key 都未設定，網站會直接使用免 Key 的 Open-Meteo。QWeather WebAPI v7 Grid Weather 已列為棄用、目前仍可用；本版先呼叫 Grid Weather，若該端點停用會在同一 QWeather provider 內自動改用官方現行 1 km 經緯度每日預報。

主畫面只顯示最高／最低溫、天氣狀況與降雨機率；展開完整行程後可查看更多指標與簡單旅遊提醒。天氣最多每 1 小時重新抓取一次，並保留最後一次成功資料供離線時參考。預報會隨時間更新，出發當天仍應以最新氣象資訊與現場公告為準。

完整行程天氣卡右下保留 **高德 / QWeather / Open-Meteo** 三個可點來源，但不再連到 API JSON 或開發文件；連結會依該列天氣定位點動態開啟對應地點。高德開啟該座標的高德地圖頁、QWeather 開啟對應行政區公開天氣頁、Open-Meteo 開啟已帶入該座標的互動預報頁。玉龍雪山／雲杉坪、普達措等獨立 weather point 會各自產生自己的三組連結。


### 介面版面

「設定」提供 **手機版（預設） / 電腦版**。手機版使用一般 responsive viewport；選擇電腦版後，即使在手機 PWA／離線狀態也會以完整桌面寬度自動縮放到手機螢幕內，保留桌面版整體比例；電腦版同樣支援主 Tab 左右切換：觸控裝置可滑動、滑鼠可拖曳、precision touchpad 可做水平手勢。版面偏好寫入瀏覽器 localStorage，線上與離線共用。產品版本仍固定為 V1；Service Worker 另外使用內部 Cache Revision 更新 App Shell，避免離線時讀到舊版 CSS／HTML。

## 出發提醒

「內容來源與查核」預設為**閉合**，需要時點一下標題即可展開；再次點擊即可收合。

航班、景區、交通、飯店與營業時間可能變動，出發前仍建議再確認實際票券、官方公告與旅行社通知。

## 離線 PWA、本機版與省流量

網站現在是可安裝的 PWA。`manifest.webmanifest`、App Shell、行程 JSON、圖示與離線管理程式都由 Service Worker 管理。一般使用者不需要理解快取細節；出發前到「設定 → 離線準備」，選好要帶走的內容後按「下載已選內容」即可。首次使用預設全選。

離線下載分組：

- **網頁核心與其他資料（必要）**：HTML、CSS、全部 V1 JavaScript、旅程 JSON、PWA manifest 與圖示。此項固定下載，不能取消。
- **旅行照片（可選，預設勾選）**：`trip-data.json` 引用的本地照片與遠端精準主圖片。全部統一放進獨立 Image Cache，方便與網站核心分開下載／清除。
- **天氣離線資料（可選，預設勾選）**：下載時先更新一次天氣，離線後沿用最後成功快取。
- Leaflet CDN 副本仍屬 best-effort 輔助快取，不作完成判定，因為探索地圖有自己的無底圖地標簡圖。

沒有網路時：

- 行程、照片、住宿、美食、故事、收藏、自定義地標正常使用。
- 探索地圖切成「雲南離線簡圖」，仍可點地標並以本站座標計算 3 公里內提案；它不是道路導航圖。
- 天氣使用最後成功快取，沒有舊資料時會明確顯示尚無資料。
- 高德／Google 導航連結仍可嘗試喚起 App，但真正的離線道路導航由地圖 App 自己負責。

手機安裝：Android Chrome 若支援會出現「安裝到主畫面」；iPhone / iPad 請用 Safari 的「分享 → 加入主畫面」。瀏覽器可能因系統儲存空間管理而清除網站資料，因此重要收藏可用「備份我的收藏與自定義」匯出 JSON；備份不包含高德／QWeather API Key。

電腦本機版：ZIP 解壓後直接執行 `START.bat`。它會啟動 `http://127.0.0.1:8765/`（若被占用會往後尋找可用 port）並自動開瀏覽器。不要直接雙擊 `index.html`，因為 `file://` 模式無法正常使用完整 PWA / Service Worker。

若要進一步把遠端精準圖片真正寫入 ZIP，可另外執行 `LOCALIZE_IMAGES.bat`；這和 PWA 的「瀏覽器離線下載」是兩種不同用途。PWA 不要求先跑該批次檔。


## 必吃／必買與鄉野奇談

美食與購物會把「必吃／必買」優先項目排在前面；這是依本次路線與來源資料整理的優先級，不代表指定餐廳或保證可攜帶入境。風俗故事中的「鄉野奇談」是地方傳說／民俗閱讀，會明確標示非史實或非已證實靈異事件。
