ONE-TIME SETUP

第一次只要綁定一次

  1. 到 Umami Cloud 建立網站，Hostname 填你的 GitHub Pages 網域。
  2. 複製該網站的 Website ID。
  3. 在網站設定建立 Share URL，只開你想看的 Overview / Events / Sessions 等頁面。
  4. 把兩個值貼到右邊，產生新的 analytics-config.json。
  5. 把它覆蓋 GitHub 裡的 data/analytics-config.json。完成後，之後照常只更新 GitHub。

關於「只有我知道的連結」

這頁沒有任何主網站入口，而且必須帶正確的網址片段才會解鎖；秘密片段不會送到 GitHub Pages 伺服器。若你的 GitHub repo 是公開的，別人仍可能看到 owner-insights.html 這個檔名，但看不到秘密片段，也無法從設定檔直接取得加密後的 Share URL。真正需要帳號級權限時，仍以 Umami 私人登入為準。
